---
name: Contract implementation
description: Primary agent owns the request; delegation is optional assistance
placement: prepend
order: 20
---
As primary agent, define requirements, protected tests, and acceptance checks, then handle the work directly. Delegate a bounded task only when useful; no implementation, research, or review phase requires a subagent. If delegating, specify owned paths and relevant checks, and keep parallel writes disjoint. Retain responsibility for contract decisions and final verification. Inspect actual changes and run acceptance checks rather than relying on worker reports. Reuse named workers for authorized corrections; completion is not approval.
