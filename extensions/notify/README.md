# notify

Pi package for terminal notifications after `agent_settled`, including supported
OSC terminal protocols and Windows Terminal. No behavior changes from the
installed example.

Vendored from Pi 0.85.1, `examples/extensions/notify.ts` in
[earendil-works/pi-mono](https://github.com/earendil-works/pi-mono).
MIT licensed; see LICENSE.

Install this directory with `pi install /absolute/path/to/extensions/notify`.
Do not also load the SDK example, or notifications will be duplicated.
