# question

Pi package for the interactive `question` tool: options, descriptions, custom
text answers, and cancellation. No behavior changes from the installed example.

Vendored from Pi 0.85.1, `examples/extensions/question.ts` in
[earendil-works/pi-mono](https://github.com/earendil-works/pi-mono).
MIT licensed; see LICENSE.

Install this directory with `pi install /absolute/path/to/extensions/question`.
Do not also load the SDK example, or the tool will be registered twice.
